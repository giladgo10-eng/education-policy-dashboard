# מערכת טיוב והאחדת רשימות (Master Data Reconciliation Engine)
### איגוד מנהלי אגפי ומחלקות החינוך ברשויות המקומיות בישראל

מערכת מקומית, עצמאית ומודרנית לטיוב והשוואה של 2–3 רשימות אקסל/CSV, התאמת אנשים (Record Linkage), טיפול בסתירות והפקת רשימת Master תקנית אחת.

---

## 🚀 דרכי הפעלה

### אפשרות 1: ממשק משתמש אינטראקטיבי בדפדפן (מומלץ)
1. היכנס לתיקייה **`04_app/`**.
2. לחץ לחיצה כפולה על **`index.html`** כדי לפתוח את האפליקציה בדפדפן (Edge / Chrome).
3. פעל לפי 7 השלבים (טעינת מקורות ➔ מיפוי שדות ➔ ניקוי ונרמול ➔ התאמות ➔ סתירות ➔ Master Preview ➔ ייצוא).

### אפשרות 2: הרצה אוטומטית מלאה מ-PowerShell
פתח את PowerShell בתיקיית הפרויקט והרץ:
```powershell
powershell -ExecutionPolicy Bypass -File .\run_cleansing_pipeline.ps1
```
הסקריפט ייצור Snapshot מלא, יבצע את הטיוב והמיזוג ויפיק את 4 התוצרים לתוך תיקיית `06_outputs/RUN_.../`.

### אפשרות 3: הפעלת בדיקות אוטומטיות
היכנס לתיקייה **`07_tests/`** ופתח את **`test_runner.html`** בדפדפן לצפייה בדוח בדיקות איכות הנתונים.

---

## 📂 מבנה התיקיות

* 📁 **`01_source_files/`** – קובצי המקור המקוריים להזנה.
* 📁 **`02_snapshots/`** – עותקים מוקפאים של המקורות לפי קוד הרצה (`Run ID`).
* 📁 **`03_dictionaries/`** – מילוני רשויות, תפקידים, שמות נרדפים וחוקים בפורמט JSON.
* 📁 **`04_app/`** – קוד האפליקציה המודולרית לטיוב רשומות.
* 📁 **`05_audit/`** – יומני ביקורת והיסטוריית החלטות.
* 📁 **`06_outputs/`** – תוצרי טיוב הרשימות.
* 📁 **`07_tests/`** – מערך בדיקות אוטומטיות.
* 📁 **`09_מערכת_פערי_תקצוב_חינוך/`** – **מערכת ניתוח פערי תקצוב וצדק חלוקתי בחינוך המוניציפלי** (דשבורד אינטראקטיבי, ניתוח חנ"מ והסעות, סימולטור מודל מתקן ומחולל ניירות עמדה לוועדות הכנסת).
