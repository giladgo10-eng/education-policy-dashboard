# research/raw README

תיקייה זו מיועדת לשמירת מסמכי מקור ראשוניים גולמיים בלבד (עותקי PDF, סריקות רשמיות, ספרי תקציב מקוריים, דוחות כנסת ולמ"ס).

## חלוקה פנימית:
1. `education-system/`: שנתוני למ"ס, נתוני ראמ"ה, דוחות מרכז המחקר והמידע של הכנסת (ממ"מ).
2. `party-platforms/`: מצעי מפלגות רשמיים, חוברות עיקרי מדיניות ופרסומים מפלגתיים מוסמכים.
3. `coalition-agreements/`: הסכמים קואליציוניים מקוריים וחתומים שהונחו על שולחן הכנסת.
4. `government-decisions/`: החלטות ממשלה רשמיות, קווי יסוד, צווי שעה ותקנות חירום.
5. `budgets/`: ספרי תקציב המדינה, חוקי התקציב, דוחות ביצוע חשכ"ל ופילוח כספים קואליציוניים.
6. `local-government/`: דוחות איגוד מנהלי החינוך, מרכז השלטון המקומי ומחקרים מוניציפליים.

> [!NOTE]
> יש להקפיד לתעד כל קובץ שנוסף כאן באינדקס המקורות `research/source-index/master-sources.md` וב-`data/sources.json`.
